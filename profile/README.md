## Welcome

**Welcome to the NC-DPH GitHub Free repository!**

This GitHub location was setup in 2026 to support data modernization efforts by NC DPH epidemiologists for the practice and training of industry standard version control and code refactoring projects. Many other US health departments and the CDC use a combination of GitHub Free and/or GitHub Enterprise for code version control, including epidemiologists at the US CDC (see the [CDC GitHub Free](https://github.com/cdcgov) site for examples).

Some important notes:

- Note that GitHub Free is different from the NC DHHS GitHub Enterprise repo (which costs ~ $250/user/year). 
- GitHub Free has both public and private repos. See here for [a feature comparison](https://docs.github.com/en/get-started/learning-about-github/githubs-plans).
- GitHub requires 2FA and a somewhat complex private key setup for code submission and membership management.
- For R or Python users, try [Positron](https://positron.posit.co/git.html) or [RStudio](https://docs.posit.co/ide/user/ide/guide/tools/version-control.html) IDE GitHub integration. Others can use standalone GitHub Desktop. Remember that Git (the standalone executable) may be required for IDE integration.
- Using GitHub for version control is **NOT** the same as using GitHub CoPilot for IDE-integrated (e.g. Positron Assistant) or GitHub-integrated AI use. To our knowledge this is not allowed at this time.

### Rules & Best Practices

NC-DPH epidemiologists are testing and training on GitHub using this space. Some (obvious) rules and expectations are as follows:

- Treat both public (code shared) and private (code hidden) repos as effectively public.
- Separate your code from your data and credentials by keeping them stored - as usual / no change - on security controlled network drives or SharePoint/OneDrive under current data governance rules.

### Setup

If you are not simply joining the web-based GitHub to review code, you will almost certainly want to setup your machine to commit code, create and answer issues and pull requests, etc. The general steps to do this are:

1. Create a "personal" account attached to your DHHS email address on the GitHub website (sign up)
2. Install Git (if wanting IDE integration) or GitHub Desktop. (Positron Source Control pane gives instructions how to install.)
3. Authenticate your account locally using a Personal Access Token (PAT) generated from your account.
4. Clone or create a repo using the website.
5. Code, commit, and enjoy!

If you need to create a brand new repo for your branch or project, speak with (for now) Deen or Mike.
